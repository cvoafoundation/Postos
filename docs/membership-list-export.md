# NCC membership-list export

The Membership Roster includes an Export membership list control for the National Commander and explicitly designated NCC members with National staff accounts. General National access does not grant the export. The Commander uses Manage NCC export access in the dialog to designate confirmed Council members. Each designation/revocation is audited. Suspended/deleted accounts and accounts whose National staff role ends immediately fail the server gate. UI access is rechecked on focus and every thirty seconds.

The export is CSV with five columns: Name, Address, Membership class, Number of votes entitled, and Voting entitlement / scope. Email, telephone, birthdate, service documents, payment information, internal IDs, and other account metadata never enter the CSV. Rows are alphabetized by recorded class and name. Active membership records are the default scope; all non-removed records are available as a separate scope, including lapsed/pending records. The selected scope applies to the entire export, independently of roster filters or the dialog search. The API returns the list as a single JSON document to avoid the REST row cap.

Annual/lifetime are dues terms, not legal membership classes. The existing database did not record member classes or vote counts. New private list-details records retain reviewed class, number of votes, and scope without inferring values from payment terms or DD214 verification. NCC reviewers may correct mailing addresses and record reviewed statutory-list details with a source/reason; those entries document this list and do not change election eligibility or system appointments. Corrections retain previous values in a private audit record. Names use the original membership roster and should be corrected there if needed.

Missing names, addresses, classes, or vote counts remain blank. Zero votes is a known entitlement and is not treated as missing. Incomplete downloads are explicitly marked REVIEW-REQUIRED. Blank fields must be resolved before presenting the file as a complete statutory list. The purpose/request reference and scope/row count of each generation are audited. Preparing a CSV does not automatically determine that a records request is legally sufficient or transmit it to any requester. NCC remains responsible for the proper population, recorded rights, completeness, and response decision.

Authorization reads authoritative profiles and a private NCC export designation table, not user-editable JWT metadata. All private tables have RLS and no user grants or policies (intentional default deny). Narrow authenticated RPCs check NCC authorization before accessing data; only the Commander can change designations. Anon/PUBLIC execution is revoked. CSV values are escaped and protected from spreadsheet formula injection.

Deploy the ncc_membership_list_export migration before the frontend. Tests cover unauthorized callers, general National staff exclusion, designation/revocation/suspension, limited fields, corrections/audit, data over 1,000 rows, CSV escaping, formula protection, hidden buttons, downloads, and account-switch cleanup.

A blank export purpose records “NCC membership-list review.” Custom purposes under five characters show a validation message when clicked rather than silently disabling the button. CSV creation attaches the download anchor to the document and retains a visible direct-download link until the dialog closes, providing a fallback when automatic downloads are blocked. URLs are revoked on replacement and dialog cleanup.
