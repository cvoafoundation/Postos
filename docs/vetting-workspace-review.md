# Post applicant vetting workspace

The old rating controls displayed 5 while persisting untouched categories as null. The handler ignored database errors, cleared entries, and showed no saved history. The new workspace requires explicit scores, reports errors without clearing entries, stamps the authenticated National reviewer on the server, and displays retained scorecards with reviewer/date, recommendations, interview responses and follow-up work. A stable review ID makes identical retries return the original saved scorecard; different findings require a new review. The pipeline quick scorecard uses the same endpoint. A National-only attribution trigger keeps the already-released legacy insert form compatible during rollout; it stamps the real reviewer even if the browser omits or forges that field. New forms enforce all five explicit scores through the RPC.

Ten guided questions cover purpose, membership/service verification, region, petitioners, officers, leadership, time/continuity, a 90-day plan, resources, and accountability. Appendix I of the supplied bylaws specifies ten Combat Members in good standing and four named officer positions for a charter petition. Questions distinguish those later charter requirements from initial review; they do not invent an approval threshold or automatically deny/approve applications. Scores and recommendations do not change stages, appointments, memberships or charter authority. Existing launch position checks remain separate.

National can request the questionnaire in My Post Applications and compose a portal-link email in their own email app. This release sends no automatic SMTP questionnaire messages and creates no new applicant accounts. Applicants need an activated account with the matching verified email or linked application ownership. They can save drafts, submit all ten responses, and update submitted answers. National sees the latest submitted snapshot; unfinished edits remain private. Submission history is retained. Version checks prevent a stale tab overwriting newer responses.

Exports include the intake, saved scorecards, attributed interview responses, recommendations, follow-up and submitted questionnaire. Drafts and unsaved reviews are excluded. Printable HTML preserves Unicode and escapes all record content. Download report produces HTML; Print / save PDF uses the browser print dialog. Save report to CVOA Drive uploads HTML to its private bucket and records it at the National-only root, never a post-shared folder. Upload/registration errors are reported, and a newly uploaded object is removed if registration fails. There is no automatic Google Drive synchronization.

All 126 regression tests and the production TypeScript/Vite build pass. Nineteen new tests include full-schema PostgreSQL execution for attribution, retries, explicit scores, authorization, questionnaire privacy and versions, submitted history, and restricted Drive exports, plus report escaping/Unicode tests. Authenticated visual verification remains limited by the cloud browser’s CVOA sign-in fetch failure; no claim of an end-to-end browser save or Drive upload is made.
